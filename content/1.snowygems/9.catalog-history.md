# 图鉴与操作记录

本页适用于 **0.0.6 修订构建，包含图鉴头颅与历史聊天显示修复**。图鉴供玩家查询，历史记录供管理员核查物品操作。

## 玩家图鉴

```text
/sgem catalog
```

权限 `snowygems.catalog`，默认包含在 `snowygems.user` 中。界面分页列出宝石配置，点击不会领取、镶嵌或消耗物品。

可查看宝石说明、适用范围、成功率，以及已配置的同类数量上限、互斥组和拆卸说明。图鉴显示的是配置说明，不是某件装备的实际属性变化模拟；真正能否拆卸以该装备的撤销记录为准。

| 外观配置 | 图鉴显示 |
| --- | --- |
| `Texture` 非空 | 使用 PLAYER_HEAD，加载配置的 base64 头颅纹理 |
| 未填写 `Texture` | 使用 Material；未填写或无法匹配时回退 PAPER |
| `Glow: true` | 添加发光效果 |
| `Display` 为空 | 使用 Name |

`/sgem view` 是管理员免费领取界面，不能代替玩家图鉴。两者使用不同权限，见[权限节点](/snowygems/permissions)。

## 管理员历史查询

```text
/sgem history Alex
```

权限 `snowygems.history`，默认 OP 可用，属于 `snowygems.admin`。参数为玩家名称，匹配不区分大小写；无需玩家此刻在线，但必须有仍在缓存中的记录。

聊天显示示例：

```text
操作记录 | Alex 最近 2 条
09-18 15:30 镶嵌 生命宝石 — 成功
09-18 15:28 拆卸 无限宝石 — 已拆卸，宝石返还
仅显示本次启动后的近期操作，最新记录在前。
```

每次最多 **5 条**，最新在前。时间格式 `MM-dd HH:mm`，采用服务器系统时区，不是玩家客户端时区。物品名称会去除颜色、混淆代码和控制字符；超过 24 个 Unicode 码点时截短显示，完整诊断信息仍保留在文件中。

### 结果含义

| 结果 | 含义 |
| --- | --- |
| 成功 | 此次使用、镶嵌、工作台操作或符文合成成功 |
| 失败，已消耗 | 本次未成功，但已消耗凭证，例如概率失败 |
| 未执行，未消耗 | 未应用效果且没有消耗该凭证 |
| 取消，费用已退 | 拆卸未完成，已尝试退款且接口报告成功；免费操作也使用此结果 |
| 退款失败，请核查 | 拆卸失败后退款接口未成功，需要核对实际余额与日志 |
| 已拆卸，宝石损坏 | 拆卸成功，损坏判定导致不返还宝石 |
| 已拆卸，宝石返还 | 拆卸成功，执行宝石返还；背包满时检查身边掉落物 |

### 查询范围

- 只查询**本次插件实例运行期间**的内存摘要，不从磁盘搜索历史。
- 所有玩家共用最近 **500 条**摘要缓存，超出后淘汰最早记录；不是每人各 500 条。
- 普通 `/sgem reload` 不清空这份缓存；正常服务器重启后重新累计。
- 聊天不显示 UUID、原始 `success=...` 等键值、异常详情或拆卸扣费中间记录。
- 不是所有点击都会记一条：在预检阶段已被拒绝、尚未进入记录点的操作可能没有摘要。

## 磁盘诊断日志

```text
plugins/SnowyGems/logs/operations-*.log
```

日志独立于 Debug，按约 **1 MiB × 5 个轮换文件**保存。格式包含 UTC 时间、玩家 UUID、玩家名、操作类型和原始详情；拆卸扣费中间记录、退款结果和异常诊断写在这里。聊天使用本地时间，文件使用 UTC，核对时注意时差。

主要覆盖使用宝石、镶嵌、工作台按钮、符文合成、拆卸及退款。查询记录不会自动补偿物品或金币；日志也没有保存完整物品备份，不能作为崩溃恢复或自动回滚依据。需要追查历史时，请及时备份轮换日志并核对实际余额和装备。

## 常见问题

**头颅仍显示为纸？** 确认运行的是包含本次修复的 JAR，且宝石 Texture 不为空。更新 JAR 要正常停服替换后启动，单独 reload 配置不会替换代码。若已显示头颅但皮肤未加载，再检查 base64 内容和纹理地址。

**聊天仍出现原始日志或混淆字符？** 修订构建不再直接发送文件日志行。重启后产生一条新操作再查询；同时检查自定义 `audit-entry` 是否仍使用 `&k`。文案节点见[语言配置](/snowygems/language#图鉴与历史查询文案)。

**找不到玩家旧操作？** 检查全局缓存淘汰与重启时间，再查看磁盘轮换日志。history 不是离线历史数据库。
