# 符文锻造与升级

使用 `/sgem rune` 打开锻造界面。左键选择配方，查看产物和材料数量，再左键确认页中央的图标执行一次。界面用不同颜色显示材料是否足够，可用底部按钮刷新材料数量或返回镶嵌台。

玩家需要 `snowygems.command` 与 `snowygems.rune`；后者包含在默认玩家权限 `snowygems.user` 中。返回镶嵌台另需 `snowygems.open`。

## 默认配方

| 操作 | 材料 | 产物 |
| --- | --- | --- |
| 合成红、蓝或绿符文 | 24 个符文碎片 | 对应颜色的一级符文 ×1 |
| 合成技能符文 | 40 个符文碎片 | 技能符文I ×1 |
| 升级红、蓝或绿符文 | 同色一级符文 ×3 + 符文碎片 ×20 | 同色二级符文 ×1 |
| 回收红、蓝或绿二级符文 | 同色二级符文 ×1 | 符文碎片 ×30 |

共 10 条配方，全部确定成功，没有额外金币费用。一级符文仍在[符文分解台](/snowygems/menus)回收，一颗获得 10 个碎片。技能符文目前只有一级。碎片的初始投放由服主通过掉落、活动或其他奖励配置决定；锻造界面不会免费提供材料。

回收和升级使用背包中**未镶嵌的符文物品**。已镶嵌在装备上的符文需先通过[拆卸](/snowygems/dismantle)取回，受拆卸费用与损坏概率影响。

## 符文的作用

符文是可拆卸的 Lore 标记，不直接修改属性、附魔或技能。镶嵌时插件把符文配置里的 Lore 行添加到装备；拆卸时按记录移除对应 Lore。属性插件、SX 系列插件或服主自己的技能插件可以读取这些 Lore 并实现实际效果。

定义位于 `gems/RuneGem.yml` 和 `gems/RuneUpgrade.yml`，仍在符文镶嵌台对应颜色槽使用。

| 符文 | 效果 |
| --- | --- |
| 红色符文II | 添加 Lore 标记 `强攻 II`，实际伤害由其他插件读取 |
| 蓝色符文II | 添加 Lore 标记 `坚韧 II`，实际生命效果由其他插件读取 |
| 绿色符文II | 添加 Lore 标记 `耐久强化 II`，实际耐久效果由其他插件读取 |

符文等级和颜色只由 Lore 标记表达，具体数值、叠加上限和生效槽位由外部属性插件约定。SnowyGems 默认镶嵌成功率为 100%，服主可在宝石定义中修改；锻造配方本身没有概率字段。

## 扣料与背包空间

- 只统计主背包和快捷栏；不使用副手、盔甲槽、光标或工作台里暂存的物品。
- 材料按 SnowyGems 宝石 ID 识别，普通物品改名不能充当材料。带同一宝石 ID 的材料即使改过显示名也会被消耗。
- 材料可分散在多格，优先消耗较小的堆叠。产物按实际堆叠上限合并或分格，也能使用扣料后空出的格子。
- 执行时重新检查材料和空间。缺料、装不下或背包发生变化时，不扣材料，不把产物掉到地上。
- 确认后刷新页面，旧页面排队的重复点击不能再次结算。重载后旧页面不可继续执行，需要重新打开。

从镶嵌台进入锻造时，原工作台先返还投入物品；若原背包已满，原工作台的返还规则仍可能将物品掉落身边。锻造只会统计已经进入背包的材料。

## 自定义配方

修改 `plugins/SnowyGems/runes/forge.yml`，然后执行 `/sgem reload`。当前读取此文件中的 `Recipes`，不扫描其他配方文件。

```yaml
Recipes:
  red-2:
    Enabled: true
    Display: '&c升级红色符文 II'
    Result: 红色符文II
    Amount: 1
    Ingredients:
      红色符文I: 3
      符文碎片: 20
```

顶层配方 ID 须唯一。`Enabled` 默认 `true`，`Amount` 默认 `1`；产物和每种材料数量必须是 1–4096 的整数，材料不能为空。`Result` 和 `Ingredients` 的键必须引用已加载的宝石 ID。无效配方会在控制台报告并跳过，其余有效配方仍可使用。

锻造直接生成指定宝石物品，不执行属性插件效果，不额外触发金币扣款或随机奖励。需要其他成本时，应修改材料组合；不要配置负数、零或空材料配方。

## 旧服升级

新文件 `runes/forge.yml` 与 `gems/RuneUpgrade.yml` 会在缺失时释放，已有配置不会覆盖。请保留或补齐 `gems/RuneGem.yml` 中的一级符文和碎片定义，否则配方关键引用检查会拒绝此次加载；重载时保留旧注册表，首次启动失败会停用插件。

命令入口可直接使用。要给已有菜单增加入口，在 `Items` 定义下面的按钮，并把 `F` 放入 `Slots` 中一个空闲的装饰位置；不要占用已有装备槽或输入槽。

```yaml
F:
  Type: RUNE_FORGE
  Material: SMITHING_TABLE
  Display: '&d符文锻造'
  Tips:
    - '&7合成、升级与回收符文'
```

如果旧菜单按 `GEM:红色符文I` 等精确 ID 限制输入，应手动加入二级 ID，或使用默认菜单的颜色文本规则。按 `CATEGORY:RuneGem` 限制的菜单也需允许 `CATEGORY:RuneUpgrade`。
